# Project Overview

This is a test Markdown document demonstrating the **markdown-reader** plugin in micro.

## Features

- Distraction-free reading by default.
- Prompts when editing is attempted.
- Faded syntax markers (`#`, `**`, `*`, `_`, `[]()`) for clean typography.

### Code Block

```lua
local micro = import("micro")
micro.InfoBar():Message("Hello world!")
```
